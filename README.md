# Fake Dating Simulator

Static, local-first dating simulator.

Features:
- 30 simulated profiles
- 40 automatic reply messages/rules per profile
- Fake profiles with local SVG images
- Discover / Like / Pass
- Simulated matches
- Chat with automatic fake replies
- Editable profiles and automatic reply rules
- In-app notifications
- Backup / Import / Clear Everything
- localStorage; no backend required for the initial version

## GitHub
Upload the project files normally. Backup JSON files generated by the app are downloaded to your device and are not part of the repository unless you manually upload them.

## Notifications
The current version uses in-app notifications only. The page/browser must be running for JavaScript-driven automatic replies and in-app notifications. Web Push can be added later without changing the local backup concept.

### Swipe
Profile cards can be dragged with touch or mouse: drag right to Like and left to Pass. The existing Like/Pass buttons remain available.

### Profile Photos
Each fake profile supports up to 4 images. Use **Edit Profiles → Add Image** to select local images. Images are stored in the browser as part of the local app data and included in backups.

### Discovery Photo Viewer
Click/tap a profile card to open its photos. Use the arrows to browse up to 4 photos.

### Profile editing access
Profile editing is available from **Manage → Profiles**; the Discover page no longer has an Edit Profiles shortcut. After Clear Everything, the app returns to Manage → Profiles so editing remains accessible.

### Image storage fix
Uploaded profile photos are stored in IndexedDB instead of localStorage, preventing blank pages/storage-quota failures with large phone images. Backups include uploaded images.

### Discover profile details
Click a profile to open a scrollable profile view with About, Lifestyle, Interests, and notes for each photo. These fields can be edited from Dating Profiles.
